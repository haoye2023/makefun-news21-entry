Entry for the make.fun bounty [Sum up 21 November's world news in one
image](https://make.fun/bounty/news-image-20261121).

`main.py` — pure Python standard library, no network — draws a newspaper
front page carrying 30 stories from Saturday 21 November 2026: a numbers
strip, three lead stories with program-drawn illustrations, twelve short
reports and a 15-item "Also on Saturday" list, plus a date-check line.
It writes a deterministic 1024x1024 `entry.png` (two runs are
byte-identical).

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
